# 🗺️ 长沙实地调研厂家地图

在线访问：**https://dearmessi2002.github.io/changsha-factory-map/**

以湘江科技创新院（湘江创智园 · 长沙市岳麓区麓景路751号）为中心的卫星地图，
标注线下实地调研过的 21 家长沙机械加工/钢材厂家（调研名单 23 条，2 家重复已合并）。

## 功能
- 默认高德**卫星影像**底图，可切换标准地图与道路/地名注记；
- 每个厂家均有编号彩色标记：🟢 精确位置、🔵 道路/片区近似、🟠 区级或推测近似；
- 点击标记查看名称、地址、定位来源，并一键跳转「高德导航 / 查看位置」；
- 左侧列表支持搜索、点击定位、「显示全部厂家」一键总览。

## 数据说明
- 坐标为 OSM/Photon 地理编码（WGS-84），页面内自动转换为 GCJ-02 以对齐高德卫星底图；
- 部分小厂无公开精确门牌，按置信度标注近似位置；其中 5 家（宇橙精密、佳硕精密、
  威铭机械、激光切割焊接加工、中锐钢构）按调研人确认标注在披塘割板市场片区，具体门牌待补充；
- 卫星影像瓦片来自高德地图。

## 更新数据
编辑 `data.js`（`window.FACTORY_DATA` 数组）即可，提交后 GitHub Pages 自动更新。
每项字段：`name` 名称、`address` 地址、`lng`/`lat` 经度纬度（WGS-84）、
`confidence` 定位精度（high/medium/low/none）、`source` 来源、`note` 备注、`dup` 名单出现次数。
